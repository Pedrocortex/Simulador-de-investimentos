# README
Digital Innovation One (DIO) - Excel com Inteligência artificial - Desafios de Projeto

An Excel-based investment simulator developed to help users analyze the long-term growth of their investments through automated calculations and interactive charts.

The spreadsheet allows users to simulate recurring investments, estimate future returns, and visualize the evolution of their invested capital and accumulated earnings over time.

## Features

- Monthly investment simulation
- Compound interest calculations
- Investment growth visualization through charts
- Automatic calculation of accumulated capital
- Configurable investment period
- Customizable monthly contribution and expected return rate
- Simple and intuitive interface built entirely in Microsoft Excel

## Technologies

- Microsoft Excel
- Excel Formulas
- Charts and Data Visualization

## How to Use

1. Download the Excel workbook.
2. Open it using Microsoft Excel (recommended).
3. Enter:
   - Initial investment (if applicable)
   - Monthly contribution
   - Expected monthly return rate
   - Investment period
4. The spreadsheet will automatically calculate the investment evolution and update all charts.

## Purpose

This project was created to facilitate the understanding of compound interest and investment growth while providing a practical tool for financial planning.

## Notes

- The simulator is intended for educational and planning purposes only.
- Investment returns are estimated based on user-provided assumptions and do not represent guaranteed financial results.

## Disclaimer

All information presented in this project is fictional and intended solely for demonstration purposes.
